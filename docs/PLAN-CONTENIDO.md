# Plan de mejora de contenido

## Objetivo

Convertir el sitio en un portal institucional útil, verificable y fácil de mantener para estudiantes, familias, empresas, egresados y personal del colegio.

## Principios editoriales

- Publicar únicamente información confirmada por el área responsable.
- Indicar la fecha de actualización en información sensible al tiempo.
- Evitar contenido demostrativo, enlaces vacíos y formularios sin funcionamiento real.
- Escribir primero para resolver una necesidad concreta del visitante.
- Mantener una sola fuente para cada dato; el calendario no debe duplicarse dentro de Noticias.
- Diferenciar claramente las fechas oficiales del CTPRGV de las fechas tentativas del MEP.

## Fase 1: portada y actualidad

- Incorporar accesos rápidos a calendario, especialidades, información y contacto.
- Mostrar actividades próximas directamente desde el calendario administrable.
- Sustituir las noticias demostrativas por publicaciones estructuradas.
- Retirar referencias obsoletas y enlaces sin destino.

## Fase 2: servicios y oferta educativa

- Crear fichas independientes para cada especialidad.
- Crear un catálogo administrable de servicios, requisitos, responsables y documentos.
- Construir un directorio institucional por departamentos.
- Añadir una sección para práctica profesional y relación con empresas.

## Fase 3: confianza y comunidad

- Verificar y documentar la historia institucional.
- Crear espacios para proyectos estudiantiles y egresados.
- Estructurar la transparencia de la Junta Administrativa.
- Incorporar indicadores institucionales que tengan una fuente comprobable.

## Matriz de responsables

| Contenido | Responsable sugerido |
| --- | --- |
| Historia, misión y visión | Dirección |
| Oferta académica | Coordinación académica |
| Especialidades y práctica profesional | Coordinación técnica |
| Matrícula, constancias y horarios | Secretaría |
| Becas, comedor, transporte y orientación | Administración u Orientación |
| Proyectos, concursos e informes | Junta Administrativa |
| Calendario y comunicados oficiales | Dirección |
| Noticias, fotografías y galerías | Responsable de comunicación |
| Directorio institucional | Dirección y Secretaría |
| Empresas y convenios | Coordinación con la empresa |

## Estado inicial

La primera entrega mantiene intacto el contenido editable de Inicio y añade componentes dinámicos para accesos rápidos y próximas actividades. Las actividades se obtienen de la misma fuente administrable que utiliza el calendario público.
